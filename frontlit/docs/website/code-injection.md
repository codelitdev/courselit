Code injection lets you add your own HTML, JavaScript or CSS to every page of your website. People use it for analytics, tracking pixels, chat widgets and site verification tags.

## Add code

<Steps>

<Step>

### Open Code Injection

Go to **Website** then **Settings** and open the **Code Injection** tab.

</Step>

<Step>

### Paste your code

There are two boxes:

- The box labelled `Code Injection in <head>` is for code that belongs in the head of the page, such as analytics or verification tags.
- The box labelled `Code Injection in <body>` is for code that belongs in the body of the page, such as a chat widget.

Paste your snippet into the right box.

</Step>

<Step>

### Save

Click **Save**. The button is enabled only after you change something. **Code injection saved.** confirms it.

</Step>

</Steps>

## Things to know

<Callout type="warning" title="Only add code you trust">

Injected code runs on every page that your visitors and learners open. A faulty or malicious script can break your site or leak visitor data. Use snippets only from providers you trust.

</Callout>

- You need the `school:write` permission to change code injection.
- API keys can't change code injection. It is reachable from the dashboard and from an AI assistant connected through your own sign-in.
