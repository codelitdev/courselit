The media library holds the images, videos and files you have uploaded to your school. Open it from **Media library** in the sidebar. Upload a file once and reuse it in pages, blog posts, products and branding.

Only real uploads are stored in the media library. Free stock photos you choose in an image picker are used directly and never become part of your library.

## Upload media

<Steps>

<Step>

### Choose how it will be used

Pick values for the three selectors above the list:

- **Category**: **Media library** for your own uploads.
- **Purpose**: what the file is for. The options are **Product artwork**, **Blog artwork**, **Lesson media**, **Downloadable file** and **School branding**.
- **Access**: **Private** or **Public**. Use **Public** for files that visitors must see, such as website images.

</Step>

<Step>

### Upload

Click **Upload media** and choose your file. Files can be up to 1 GB.

</Step>

</Steps>

New uploads appear at the top of the list.

## Find a file

The list shows each file with its thumbnail, file name, type and how many places use it, for example `1 reference`. Type in the search box and click **Search** to find files by name or type.

Set **Category** to **User uploads** to see files uploaded by your learners, such as profile photos and images in community posts.

## Edit alt text

Click **Edit alt text** on a file, enter a short description of the image in the prompt and confirm. Good alt text helps visitors who use screen readers.

## Delete a file

Click **Delete** on a file and confirm. A file can only be deleted when nothing uses it. If the file shows one or more references, the **Delete** button is disabled. Remove the file from the places that use it first.

When you delete a page or blog post, the files that only that page or post used are deleted for you.

## Permissions

You need `media:read` to see the library, `media:write` to upload and edit alt text, and `media:delete` to delete files.
