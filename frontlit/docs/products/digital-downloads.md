A **digital download** is a product made of one or more files that learners get straight away, such as a guide, template, preset or ebook. You can sell it, or give it away for an email address as a [lead magnet](/docs/products/lead-magnets).

Digital downloads share most of their management screens with courses. This page covers what is different.

## Create a digital download

Open **Products**, select **New product** and choose **Digital download**. Under **How people get it**, choose **Sell it** or **Lead magnet**, enter a **Title** and select **Create draft**. See [Create a product](/docs/products/create-a-product).

A new download starts with one section, named **First section**, to hold its files. A download always keeps at least one section, and you cannot add more.

## Add files

On the product's **Files** tab, select **Add file** to open the file editor.

<Steps>

<Step>

### Name the file

Enter a **Title**. This is what learners see for the file.

</Step>

<Step>

### Save the file

Save with **Save draft** or **Save and make live**. The editor then reopens so you can attach the actual file.

</Step>

<Step>

### Attach the media

Under **Media**, select **Select or upload media** and choose a file from your media library, or upload a new one. Any file type is accepted. Files are stored privately, so only people with access can download them.

</Step>

</Steps>

Each file has a **Live** or **Draft** switch, just like a lesson. Learners only get live files. **New files start as** at the bottom of the tab sets the default for new files. See [Sections and lessons](/docs/products/sections-and-lessons) for how the list works.

## Set how people get it

A download needs at least one active [payment plan](/docs/products/payment-plans) before it can go live, and at least one live file. Use a free plan to give it away, or a paid plan to sell it. Paid plans need a connected payment provider.

For a free download that collects email addresses, turn on **Lead magnet** in **Settings**. See [Lead magnets](/docs/products/lead-magnets).

Then publish it. See [Publish a product and control visibility](/docs/products/publish-and-visibility).

## What learners get

Once a learner has access, the download's sales page reads "You already have access to this download." with a **Download files** button. Selecting it prepares a single ZIP file, named after the download, that contains every live file that has media attached.

- Only **live** files are included. Drafts are left out.
- The ZIP can contain up to 300 MB of files in total. If your files are larger, the learner sees "Unable to prepare the download."
- Learners also find the download under **Products** in their dashboard, labelled **Digital download**.

## Track downloads

On **Overview**, the number tile reads **Downloads** instead of the course completion count. On the [Customers](/docs/products/customers) page, a **Downloaded** column shows **Yes** or **Not yet** for each customer.

## What does not apply to downloads

Downloads do not have these course features:

- [Drip schedules](/docs/products/drip-schedules)
- [Quizzes](/docs/products/quizzes) and [SCORM lessons](/docs/products/scorm)
- [Free preview lessons](/docs/products/free-preview-lessons)
- [Certificates](/docs/products/certificates) and [discussions](/docs/products/discussions)
- [Preview](/docs/products/preview-a-course)
